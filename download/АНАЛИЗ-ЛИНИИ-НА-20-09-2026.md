## 1. С ЧЕГО НАЧАЛИ

Старт (18.09, Task 1) был утилитарным — **унифицировать UI двух экспортёрских скриптов**: стиль Polymat v20
в Universal AI Chat Exporter v22.1.6 → v22.1.7 (смоук 41/41). Никакой «разведки» и «struct» в стартовой
задаче не было. Дальше линия расширялась по внутренней логике: восстановление UACE v26 → стилизация 27.x →
темы с WCAG-контрастом → **перелом 19.09**: предложение стандарта от B → фриз **PML-PANEL 1.0** (§1–17,
P1–P14) → контракт **PML-STRUCT r1/r2** (снимок страницы: meta/dom/scroll/mut/anchors + скоринг с гейтами
G1–G4 и солью `PMLSTRUCT`) → стратегплан с ролями (A — канон/UPOLY, B — эталон UACE/приёмки, владелец —
курьер ≤40 строк) → резка эталона **UPOLY v1.0.0-sk** (панель + Модуль I разведки + реестр действий).

## 3. СУХОЙ ОСТАТОК

- **Код**: линейка UPOLY 1.0.0→1.0.5 + UACE 27.4.x→27.5.0. Каждая версия — фикс с регрессией в тесте.
- **Канон**: замороженный мастер панели, R1/R2-черновики struct, предаудит ЧК-1 (3 блокера + 9 дивергенций), Ф2-архив, протокол ЧК-1.
- **Процесс**: worklog 29 задач, md5-фризы, ACCEPT/AMEND, уроки закреплены регрессиями (главный: DOM-стабы обязаны совпадать с реальными API).
- **Главная ценность**: доказано, что две независимые сборки живут на одной странице по формальному
  контракту и готовы обменяться детерминированным структурным снимком. Не изобретение, а **сборка
  известных идей в связанный стандарт с «0 угадываний»**.

## 4. КТО ГДЕ КОГДА И НА КАКОМ ЯЗЫКЕ (ландшафт, свежесверено поиском)

| Компонент | Предки |
|---|---|
| Детекция повторяющихся структур | **Wrapper induction**: Kushmerick (AAAI 1997, США/Ирландия), RoadRunner (VLDB 2001, Италия), обзор Laender (ACM 2002, Бразилия) — Java/Python, английский. **LLM-эра**: D2Snap «DOM Downsampling for LLM Web Agents» (arXiv 08.2025), browser-use/Skyvern (Python, 2024+), **Playwright MCP a11y-снапшоты** (Microsoft, TS, 2025–2026, ~200–400 токенов) — де-факто стандарт агентного вида страницы |
| Структурные хэши | minhash — Broder (AltaVista, 1997), simhash — Charikar (Google, 2002); FNV-1a — Fowler/Noll/Vo (Bell Labs, 1991, C). Русский след: `cyberok-org/similarity` (Go, CyberOK) |
| Семантика страницы (landmarks) | WAI-ARIA (W3C, 2007–2014); Playwright aria snapshots (2024+) |
| Надстройки над чужими страницами | Greasemonkey (2004) → Tampermonkey (~2010) — но синглтон-контракт «первый побеждает» с mount(config) там никто не формализовал; Readability (Mozilla) — предок uniformity-скоринга |
| Протокол сотрудничества | RFC-процесс (IETF, с 1969) + ADR (2011); мультиагентные фреймворки (AutoGen/CrewAI/LangGraph, Python) — но **курьерская схема** (2 ИИ-сессии + человек-ретранслятор + MD + md5-фризы) в открытых практиках не описана |

**Честная оценка новизны**: по компонентам всё имеет предков; **комбинация** — детерминированный
кросс-сборочный struct-контракт + гейты с D4-консерватизмом + формализованный синглтон + курьерский
процесс — в открытом доступе не найдена. Весь мировой канон на английском; наш протокол на русском —
фактически строим русскоязычный инженерный канон.

## 5. АКТ ИНТЕГРАЦИИ: ландшафт → код (UACE 27.5.0, «усвоение ландшафта»)

Принцип: **аддитивно, вне хэш-канона r2 §5** — канон-векторы `3124194f / 0aebe13f / a9ecc18e / a03cc27b /
491154e6` не изменились (проверено core-тестом), канонные поля struct не расширялись (ext-полей нет).

| Ландшафт | Взято в код | Что именно | Граница/отличие |
|---|---|---|---|
| Playwright MCP a11y-снапшот (2025–2026, де-факто стандарт) | `agentView(struct)` + кнопка «Копировать agent-view» (Разведка + Действия) | формат «- роль [ref=lN] path=…», заголовок page urlHash+ratio, ref-нумерация | **БЕЗ имён**: accessible name = текст страницы — §15 «0 текста» важнее паритета с оригиналом (вопрос к r3) |
| D2Snap, DOM downsampling (arXiv 08.2025) | `downsample(struct, budget)` | двухфазно: coverage (page → landmarks → mounts → groups по канонному рангу I.2.5) + selection добором под бюджет; «токен» ≈ 4 символа; дефолт 400, пол 60 (заголовок обязан выживать); хвост «… +N узлов за бюджетом» | детерминировано, без рандома; порядок — канонный, не FNV-перетасовка |
| Simhash (Charikar, Google 2002) | `simhash64` (pure) + `domSim64(struct)` + `simBetween(a,b)` | 64-бит фингерпринт мультмножества структурных фич (landmarks ×3, группы ×2, mounts ×1), две salt-половины `SIM1>/SIM2>` | вне хэш-конверта; порог «один класс страницы» — калибровка ЧК-3 (измерено: близнец d=4, чужак d=31 → рабочая вилка ≤12 бит) |
| Minhash (Broder, AltaVista 1997) | `compareStructs(a,b)` | точный Jaccard по sigHash групп + Хэмминг фингерпринтов | наборы ≤12 — точный подсчёт дешевле аппроксимации; линия minhash уважена, аппроксимация не нужна |
| Wrapper induction (Kushmerick 1997, RoadRunner 2001) | уже в коде с 27.4.x | `findGroups`: детекция повторяющихся детей по sigHash, uniformity, отсечения 32px/0.4·h | ничего добавлять не требовалось — проверено полем (f0338710 ×2) |
| Readability (Mozilla) | уже в коде | uniformity-скоринг групп + гейты G1–G4 | — |
| Greasemonkey/Tampermonkey | уже в коде | синглтон P13 «первый побеждает» + mount(config) | в GM-линейке не формализовано — наша добавка |

**Не взято осознанно**: чтение текста/имён для agent-вида (§15), рандомизированные аппроксимации
(minhash-подписи), токенизаторы конкретных вендоров (бюджет — символический, «≈4 символа/токен»).
