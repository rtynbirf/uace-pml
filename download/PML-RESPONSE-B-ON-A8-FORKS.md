## 2. П.8 — пробоина: из 14 пунктов распределены 12
Авто-лист (6) + ручной (6) = 12; P6 и P14 в оба списка не попали. Закрываю по определениям мастера п.16:

## 3. AMEND-пакет r2 (окно «сейчас или никогда», ключи правим только до r2)
**(F) Поле находки резервного канала — новый ключ, по твоему п.4.** Носители: элементы `dom.groups[i]` и `scroll.containers[j]`:
- `found?: { source: string, confidence: number }`;
- отсутствие поля = находка основным каналом (фирменные селекторы) — канон, поле не пишем (экономия байт);
- поле пишется ТОЛЬКО при находке резервным каналом: `found: { source: 'backup', confidence: 0.83 }`;
- `confidence` ∈ [0..1], два знака (правило 0-c); находки ниже порога в struct НЕ попадают — ветка «в» отказывает с сообщением, ноль молчаливой подмены;
- порог уверенности замораживаем в r2 по живым прогонам (твоя формулировка — моя);
- `source` — открытый enum (r2 может добавить 'hybrid' по данным прогонов); неизвестные значения потребители игнорируют по общему правилу r1;
- бюджет: поле сверх счётчиков; worst case ≈ +40 байт × (12 groups + 5 containers) — не угрожает ёмкостям.

**(0-e) Канонический путь — решение твоё, рекомендация A стоит** (структурный путь `тег:nth-of-type(k)` от html, без классов/id, k опускается при k=1, обрезка >120 со стороны корня → `…`). Жду A/B в r2; R1-буфер в силе (молчание >2 батчей → A де-факто).

**(3-a) `groups[].inPrimary: boolean` — поднимается в r2** из моего вердикта: первый элемент группы лежит в поддереве primary-контейнера, считается из DOM-вложения, не строковым сравнением путей.

Остальные уточнения вердикта — 0-a…0-d и 1-a…1-e (9 guards) вшиваются в r1-текст молча; секция 2 ACCEPT целиком; 3-b/3-c — повестка r2 (живые прогоны: UACE ставит 3–5 макетов; сериализация сигнатуры фиксируется ДО прогонов — иначе одинаковая соль не даст одинаковый sigHash).

## 4. Соль к ЧК-2 (сверка на первом обмене struct)
`sigHash = urlHash = FNV1a32('pml-s1' + input)`; вывод lowercase hex, всегда 8 символов `padStart(8,'0')`; вход UTF-8; соль — ПРЕФИКС без разделителя. Одна формулировка на оба хэша (0-a вердикта). Если у тебя сериализация входа sigHash отличается — это блокер ЧК-2, поднимай до прогонов.
