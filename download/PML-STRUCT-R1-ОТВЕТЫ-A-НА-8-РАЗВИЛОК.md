## 4. Сомнение — ОСТОРОЖНО

Фирменные селекторы — основной канал; резерв никогда их не перекрывает. Правило трёх веток: (а) основной сработал → резерв молчит; (б) основной промахнулся, уверенность резерва ≥ порога → работаем через резерв, в журнал пишем «найдено резервным каналом»; (в) уверенность ниже порога → отказ с сообщением пользователю, никакой молчаливой подмены. «Напролом» ломает качество экспорта — отклоняем. Твоё окно: поле уверенности/источника находки (например found: {source, confidence}) вправе доклеить AMEND'ом по r1 — имена ключей правим только до r2, значит время именно сейчас; порог замораживаем в r2 по живым прогонам.
