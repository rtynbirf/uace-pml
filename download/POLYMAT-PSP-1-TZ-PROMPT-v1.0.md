## 1. НАЗНАЧЕНИЕ И ПРЕДПОСЫЛКИ

1.1. Предпосылки. Веб-страницы воспроизводятся на платформах Windows/macOS/Linux/Android/iOS, на устройствах от смартфона до 8K-монитора, при DPR 1–4 и частоте обновления 30–240 Гц. Отрасль не имеет единого измеримого стандарта оценки того, как структура страницы воздействует на здоровье пользователя: зрение (контраст, синесветовая нагрузка), вестибулярный аппарат (мерцание, движение), когнитивную сферу (перегрузка интерфейса). Продукт создаёт измеримую основу такой оценки: профилирует устройство и каркас страницы и выдаёт вердикты по зафиксированным метрикам.

1.2. Продукт: userscript (UserScript metadata-блок, ECMAScript 2020) для менеджеров Tampermonkey 5+, Violentmonkey, Greasemonkey 4+, Userscripts (iOS).

1.3. Функции продукта:
- F1. Сбор всех доступных через стандартные API данных об устройстве и среде отображения (модуль D, раздел 4).
- F2. Сбор структурной модели страницы — «каркас»: разметка, геометрия, слои композитинга, CSS-механика, таблицы, формы — без захвата содержимого (модуль S, раздел 5).
- F3. Вычисление метрик безопасности страницы для здоровья: контраст (APCA + WCAG 2.2), синесветовая нагрузка, мерцание/движение, когнитивная нагрузка, типографика чтения (модуль H, раздел 6).
- F4. Формирование двух отчётов: машиночитаемый JSON (7.1) и однофайловый автономный HTML, оформленный по нормам 7.2 (модуль R).

1.4. Область воспроизведения отчёта (ОБЯЗАТЕЛЬНО корректный рендер во всём диапазоне): viewport по ширине 320–7680 px; DPR 1–4; частоты 30–240 Гц; цветовые охваты sRGB/Display-P3; темы светлая/тёмная/форс-цвета; ввод мышь/тач/клавиатура.

1.5. Продукт — диагностический наблюдатель: только чтение хоста (раздел 2), сбор по явному согласию (раздел 10), ноль сетевой активности.

## 4. МОДУЛЬ D: ПРОФИЛЬ УСТРОЙСТВА

4.0. Все чтения — через стандартные API; каждое поле обёрнуто в изолятор отказа; недоступное → `availability:"unavailable"`. Асинхронные сборщики — через `Promise.allSettled`.

4.1. Экран и окно (ОБЯЗАТЕЛЬНО): `screen.width/height/availWidth/availHeight`; `screen.orientation.type/angle`; `devicePixelRatio`; `window.innerWidth/innerHeight/outerWidth/outerHeight/screenX/screenY`; `visualViewport.{width,height,scale,offsetTop,offsetLeft}`; множество `matchMedia`: `prefers-color-scheme (dark|light)`, `prefers-contrast (no-preference|more|less|custom)`, `prefers-reduced-motion`, `prefers-reduced-transparency`, `forced-colors`, `inverted-colors`, `color-gamut` (максимальный из srgb|p3|rec2020), `dynamic-range`, `video-dynamic-range`, `update (fast|slow|none)`, `pointer/hover/any-pointer/any-hover`, `display-mode`, `scripting`, `monochrome`.

4.2. Частота обновления дисплея: замер `requestAnimationFrame` — 120 кадров, первые 10 отбрасываются; метрика — медиана Δt → Гц; сырое значение сохраняется вместе с нормализацией к стандартному ряду (60|75|90|120|144|165|240). Если за окно наблюдения собрано <60 кадров (троттлинг фоновой вкладки) — `availability:"unreliable"`.

4.3. Платформа (ОБЯЗАТЕЛЬНО): `navigator.userAgentData` (brands, mobile, platform) + `getHighEntropyValues(['architecture','bitness','model','platformVersion','wow64'])` при доступности; `navigator.platform` (legacy, помечен deprecated); `hardwareConcurrency`; `deviceMemory`; `maxTouchPoints`; `webdriver`; `pdfViewerEnabled`; `cookieEnabled`; `onLine`; `languages` (только коды, без полных строк); IANA-часовой пояс и смещение UTC; `storage.estimate()` → quota/usage.

4.4. Сеть (Network Information API, при наличии): `effectiveType`, `type`, `downlink`, `downlinkMax`, `rtt`, `saveData`. Только чтение атрибутов, без активных замеров трафика.

4.5. Графика: наличие WebGL1/WebGL2; `WEBGL_debug_renderer_info` → `UNMASKED_VENDOR_WEBGL`/`UNMASKED_RENDERER_WEBGL` (факт маскировки драйвера фиксируется); `MAX_TEXTURE_SIZE`, `MAX_RENDERBUFFER_SIZE`, `MAX_VIEWPORT_DIMS`; наличие `OffscreenCanvas`.

4.6. Медиа-декодирование (статическая матрица, без сети): `MediaSource.isTypeSupported` для набора: `avc1.640028`, `hvc1.1.6.L123.00`, `vp09.00.10.08`, `av01.0.08M.08`, `mp4a.40.2`, `opus`, `flac`.

4.7. Батарея (при наличии `navigator.getBattery()`): `charging`, `level`. API опционален (удалён в ряде браузеров).

4.8. Формат каждой записи: `{category, key, value, unit|null, availability: granted|unavailable|masked|permission-required|unreliable, source_api}`.

## 5. МОДУЛЬ S: КАРКАС СТРАНИЦЫ (БЕЗ СОДЕРЖИМОГО)

### 5.1. Обход
Итеративный DFS на стеке (рекурсия ЗАПРЕЩЕНА — риск переполнения стека). Лимиты: глубина 64; 20 000 узлов с детализацией (далее — только счётчик `{truncated:true, count_over}`); Shadow DOM — композитный обход `shadowRoot`; `<iframe>` same-origin — рекурсивный обход с `frame_id`; cross-origin — терминальный узел `{type:"iframe", origin: hostname, bbox}`; `<template>/<script>/<style>/<noscript>/<link>/<meta>` — в дерево не входят, учитываются счётчиками.

### 5.2. Запись элемента (нормативный набор)
- `tag`, namespace (html|svg|mathml);
- роль: явная (`role=""`) либо имплицитная по HTML-ARIA (W3C); класс landmark: banner|navigation|main|complementary|contentinfo|search|region(именованная)|form;
- heading: уровень h1–h6 либо `role=heading`+`aria-level`;
- геометрия: `getBoundingClientRect()` → {x,y,w,h}; статус видимости: displayed|hidden(display:none)|invisible(visibility:hidden)|transparent(opacity<0.05)|clipped(нулевая площадь)|offscreen;
- стековые признаки (для 5.7): position, z-index, opacity, transform≠none, filter, backdrop-filter, will-change, isolation, mix-blend-mode, contain(paint|strict|content), mask;
- структурные ARIA: hidden, expanded, current, level, posinset/setsize, live, busy, modal;
- интерактивность: `tabindex`, disabled, readonly; класс ссылки по href: internal|external|in-page-anchor|javascript|mailto|tel|blob|other (для external — hostname, полный URL ЗАПРЕЩЁН);
- классы и id-хеш (2.4);
- инлайн-стиль: факт наличия + число деклараций (без значений).

### 5.3. Текст и медиа (структурные метрики вместо содержимого)
- текстовый узел → `{length, words, has_digits:boolean, in_link:boolean}` (смежные объединяются);
- изображение → `{naturalW, naturalH, aspect, loading_attr, has_alt:boolean, srcset_count, area_share}`;
- видео/аудио → `{has_controls, autoplay_attr, muted_attr, loop_attr, duration_known:boolean}`;
- canvas → {w,h}; svg → {viewBox, child_count}.

### 5.4. Таблицы
На каждую `<table>`: rows, cols_max, факты caption/thead/tbody/tfoot, th_count, использование th/scope, факты colspan/rowspan, nested_tables_count, индекс первой строки-заголовка (строка, где ≥60 % ячеек — th); агрегат по ячейкам: средняя длина текста (число, сам текст ЗАПРЕЩЁН).

### 5.5. Формы
На каждую `<form>`: факт method, action-hostname (или same-origin), гистограмма типов input, счётчики textarea/select/meter/progress/output, доля контролов с явной/неявной label, факты fieldset/legend, required_count, факты autocomplete, факты aria-invalid.

### 5.6. CSS-инвентарь и цветовая карта
5.6.1. Источники: `document.styleSheets` (same-origin и inline `<style>`; cross-origin — только факт наличия, `cssRules` недоступны — фиксируется). Полные списки условий: `@media` (текст условий), `@supports`, `@container`, имена `@layer`, регистрации `@property`.
5.6.2. Селекторы: распределение по типам (class|id|tag|attribute|pseudo-class|pseudo-element|universal|составные); средняя и максимальная специфичность (тройка a,b,c); счётчик `!important`; счётчик inline-деклараций; число обращений `var()` и уникальных имён custom properties (только имена).
5.6.3. Единицы и функции: regex-инвентарь по cssText правил: px|rem|em|%|vw|vh|dvh|svh|lvh|ch|ex|fr|cm|mm|in|pt|q|deg|rad|turn; функции calc|min|max|clamp|fit-content|min-content|max-content|var|env|color-mix|oklch|oklab|lab|lch|color()|hsl|rgb|семейство gradient*|filter-функции. Результат — гистограммы.
5.6.4. Цветовые значения из computed style каждого собранного элемента: `color`; `background-color`; все цветовые стопы `background-image` (парсер linear-/radial-/conic-gradient: углы и координаты стопов); `border-*-color`; `outline-color`; `text-decoration-color`; цвета всех `box-shadow`; цвета в filter/backdrop-filter; computed цвета псевдоэлементов `::before`/`::after`.
5.6.5. Конвертация: все цвета → OKLCH по CSS Color Module Level 4 (официальные матрицы OKLab); входы sRGB и Display-P3; хранение `{L 0..1, C, H°, α}`.
5.6.6. Эффективный фон: для каждого текстового/интерактивного узла — композитный расчёт снизу вверх: α-over композиция (Porter–Duff) по цепочке предков до первого непрозрачного фона; учёт цепочки opacity и изоляции blend-групп (`mix-blend-mode` действует в пределах stacking context). Результат: пары (effective_fg, effective_bg) с площадным весом.
5.6.7. Цветовая карта страницы: гистограмма уникальных OKLCH-цветов с площадными долями; топ-20 пар fg/bg по суммарной текстовой площади; распределение L фонов и текста (среднее/медиана/P5/P95); доля площади за пределами sRGB при широком охвате. Площадные доли считаются в двух диапазонах: viewport (первый экран) и весь документ.

### 5.7. Слоевая модель (композитная декомпозиция страницы) — ОБЯЗАТЕЛЬНО
5.7.1. Постулат: страница воспроизводится как упорядоченный по z стек слоёв композитинга — та же модель, по которой строится изображение в слоевых графических редакторах и layered-canvas веб-приложениях (референс подхода: app.reve.com, где изображение собирается из независимых слоёв). Слой = множество элементов, разделяющих контекст стека/композитинга и диапазон z.
5.7.2. Границы слоёв определяются по стековым признакам 5.2 (position+z, opacity<1, transform, filter, backdrop-filter, will-change, isolation, blend, contain:paint) плюс корневые контексты (html, body). На каждый слой: id, диапазон z, bbox (объединение), площадь, opacity, blend, число элементов, доминирующие цвета (из 5.6.7), контраст-пары внутри слоя.
5.7.3. Классификация слоёв: L0 фоновые (html/body background, fixed-фоны); L1 layout-каркасы (grid/flex-контейнеры верхних трёх уровней); L2 контентные блоки (main/section/article, крупные текстовые массивы); L3 позиционированные перекрытия (absolute/fixed/sticky с z>0); L4 интерактивная карта (все ссылки/кнопки/поля — отдельная плоская проекция); L5 оверлеи (dialog, [popover], aria-modal, tooltip, toast, ::backdrop); L6 эффектные (shadow-кастеры, blur/filter-зоны, blend-группы).
5.7.4. Отчёт содержит статическую SVG-диаграмму «exploded stack»: вертикальное смещение слоёв пропорционально z-рангу; каждый слой — прямоугольник bbox с подписью роли и id; ноль анимаций; типографика подписей — по 7.2.

### 5.8. Информационная архитектура
- карта зон: % площади по landmark-классам (viewport и документ);
- порядок чтения: сортировка топ-блоков по (y, x) с допуском строки ±0.5 высоты блока против DOM-порядка → число инверсий и доля;
- глубина контента: средняя/максимальная глубина от body до текстового узла;
- семантика: доля семантических элементов (не div/span) среди контейнеров;
- навигация: количество nav; число top-level пунктов каждой nav (прямые дети-ссылки);
- заголовки: полная иерархия уровней, число пропусков уровней.

### 5.9. Динамика (опция, по явному включению пользователем)
MutationObserver, окно 10 с: счётчики мутаций по типам (childList/attributes/characterData), появление/удаление оверлеев (L5), смена системной темы за окно наблюдения. Содержимое мутаций — ЗАПРЕЩЕНО.

## 6. МОДУЛЬ H: МЕТРИКИ БЕЗОПАСНОСТИ ДЛЯ ЗДОРОВЬЯ

### 6.1. Контраст (зрение)
6.1.1. ОБЯЗАТЕЛЬНА реализация APCA 0.1.9 (SAPC-4) без упрощений. Нормализация: `Y = sRco·R_lin + sGco·G_lin + sBco·B_lin`, где `channel_lin = (c_srgb/255)^2.4` (mainTRC=2.4, не 2.2). Константы: sRco=0.2126729, sGco=0.7151522, sBco=0.0721750; normTXT=0.57, normBG=0.56, revTXT=0.62, revBG=0.65; blkThrs=0.022, blkClmp=1.414; scale=1.14; loClip=0.1; offset BoW=−0.027, WoB=+0.027; deltaYmin=0.0005. Мягкий чёрный кламп: `Y<blkThrs → Y += (blkThrs−Y)^1.414`. BoW (тёмный текст на светлом): `SAPC=(Ytxt^0.57 − Ybg^0.56)·1.14`, при `|SAPC|<loClip → 0`, иначе `Lc=SAPC−0.027` (отрицательный знак). WoB (светлый на тёмном): `SAPC=(Ytxt^0.62 − Ybg^0.65)·1.14`, иначе `Lc=SAPC+0.027`.
6.1.2. Параллельно — контраст-рейшо WCAG 2.2 (относительная luminance) для совместимости с существующими инспекциями.
6.1.3. Классы по |Lc|: ≥90 — основной длинный текст; 75–89 — заголовки и акцентный текст; 60–74 — крупный текст (≥24 px либо ≥18.66 px bold) и второстепенный; 45–59 — не-текстовые UI (границы, иконки, фокус); 30–44 — декоративные индикаторы; <30 — fail.
6.1.4. Метрики: доля текстовой площади и числа текстовых узлов по классам; **CS (Contrast Safety Score)** = 100 × (доля текстовой площади с Lc≥60, для заголовков требование ≥75) − 2 × (процент текстовой площади fail-класса <30). Формула фиксируется в коде и дублируется в отчёте.

### 6.2. Синесветовая нагрузка (BLWEI)
6.2.1. Прокси-метрика меланопической стимуляции: `BLWEI = Σᵢ shareᵢ · (0.15·R_lin + 0.30·G_lin + 0.55·B_lin)ᵢ`, где shareᵢ — площадная доля поверхности (фона) либо текстовой площади (текста). Компоненты — линейный sRGB. Метрика помечается в отчёте как инженерная аппроксимация направления α-opic чувствительности (CIE S 026:E:2018), не её замена.
6.2.2. Классы: ≤0.20 низкая; 0.20–0.35 умеренная; >0.35 высокая (рекомендация тёплой темы/ночного режима). Отдельно: доля поверхностей с B_lin>0.5 и R_lin<0.2 («чистые синие»).

### 6.3. Мерцание и движение (вестибулярный риск)
6.3.1. Инвентарь: все `@keyframes` (имена, длительности, итерации), декларации animation/transition (свойства, длительности, задержки), `scroll-behavior`, scroll-driven анимации, autoplay-видео.
6.3.2. **FRI (Flicker Risk Index)**: 0 — нет движения; 1 — конечные анимации ≤400 мс, только transform/opacity; 2 — infinite-анимации либо layout-триггерящие свойства (width/height/top/left/margin); 3 — потенциальный флэш-ритм >3 Гц (период осцилляции свойства по keyframes, 2 перехода на цикл) — CRIT, порог фотосенситивности WCAG 2.2 SC 2.3.1.
6.3.3. **MI (Motion Index)**: счётчики параллакс-паттернов (translate от scroll), принудительного smooth-scroll, hover-scale >1.1, infinite-областей.

### 6.4. Когнитивная нагрузка (CLI)
Сумма детерминированных штрафов (веса фиксируются в коде, суммарно ≤100; CLI = 100 − штраф):
- фокальные кластеры h1–h3 в первом viewport (кластеризация пересечением bbox) >4 → −15;
- top-level пунктов nav >7 (эвристика объёма рабочей памяти 7±2, помечена как эвристика) → −10;
- пропуски уровней заголовков → −5 каждое (до −15);
- >2 шрифтовых семейств → −10;
- >6 различных кеглей на 1000 px² viewport → −10;
- имитаторы системных диалогов (fixed, z≥1000, тень+скругление, вне dialog/[popover]) → −10;
- hover-only-афордансы (:hover меняет только цвет/фон, без зеркала в :focus-visible) → −10;
- инверсии порядка чтения (5.8) >5 % блоков → −10;
- количество nav >3 → −5; отсутствие `<main>` → −5.

### 6.5. Типографика чтения (RTI)
Кандидаты параграфов: p, li, dd, blockquote, caption, td, а также div, все дети которого — текстовые/инлайн-узлы. Для каждого: ширина колонки, кегль, множитель line-height, letter-spacing, факт text-transform:uppercase. Оценка `CPL_est = ширина_px / (0.5 × кегль_px)` — помечается estimate (0.5 em — медианная ширина глифа смешанного кирилло-латинского набора). Оптимальная полоса 60–90 CPL, line-height 1.4–1.8. Штрафы: выход за полосу CPL, uppercase-массивы >200 символов по длине узла, letter-spacing <−0.02 em. RTI = 100 − штрафы.

### 6.6. Сводный индекс HSI
`HSI = 0.35·CS + 0.15·(100−BL_norm) + 0.15·(100−FRI_norm) + 0.20·CLI + 0.15·RTI`. Нормировки: BL_norm: {низкая=20, умеренная=55, высокая=90}; FRI_norm: {0=0, 1=15, 2=55, 3=100}. Грейды: A ≥90, B ≥75, C ≥60, D ≥40, иначе F. Продукт только измеряет и классифицирует; управление отображением остаётся у пользователя.
