УСТАНОВКА
=========
1. Tampermonkey → «Создать новый скрипт» → вставить содержимое .user.js → Сохранить.
   (Или перетащить файл в браузер при включённом «Разрешить доступ к URL файлов».)
2. Обновление с v28.x: НЕ поверх — сначала удалить старую версию скрипта
   (другое имя пространства настроек не гарантировано), затем поставить v29.
3. Горячие клавиши канона: E/D/C/S/X/I (E — экспорт, I — Паспорт).
