# PML-PANEL 1.0 — ЗАМОРОЖЕННЫЙ ТЕКСТ (мастер, идентичен у обоих)

**1. Имя, синглтон, API.** Панель PML-PANEL 1.0; классы и токены `pml-`; одна страница — одна панель.
`window.__PML_PANEL_API__ = Object.freeze({ version, ping(), mount(config), setBadge(state), log(level, msg), renderRecon(struct), renderActions(list), getPassport() })`.
Все вызовы до mount() — в очередь, проигрываются после монтирования (при takeover — заново).
`config = { name, version, hotkeys: [{key, label, run}] }`. `ping()` → `{version, alive: true, owner}`.
`mount(config)` при живой панели: вторую панель не создаёт; регистрирует только хоткеи, возвращает `{attached: true, owner}`; хедер/паспорт не переписывает.
Takeover: хост отсутствует/отсоединён >5 с (isConnected + ping) → поздний скрипт пересоздаёт панель, становится владельцем API, очередь проигрывается заново, warn в журнал.

**2. Монтаж и выживание.** Хост `<div id="pml-host">` в `document.documentElement`; ShadowRoot open; один `<style>` внутри рута; fallback-див `pml-` только при недоступном attachShadow; только классы-селекторы. Watchdog 2 с: `isConnected` → тихое перемонтирование в прежнюю точку, без MutationObserver. Полная самоочистка при выгрузке.

**3. Разведка перед монтажом.** Кандидаты I-4a (fixed/sticky, top < 0.15vh, h ∈ [32;96], w ≥ 120) → приоритет: свободный кандидат → right:16/top:16 → bottom:16/right:16. Внутрь интерактивных узлов не монтируемся. z-index = max(скан fixed/sticky +1, 1000), потолок 2147483000. Primary scroll-контейнер (I-2) не перекрываем.

**4. Токены (имена заморожены).** `--pml-bg, --pml-fg, --pml-fg-dim, --pml-line, --pml-accent, --pml-accent-tx, --pml-ring, --pml-ok, --pml-warn, --pml-crit, --pml-radius (12px), --pml-fs (14px)`.

**5. Темы.** {system, light, dark, warm}; хранение — в `pml_panel_v1`. system = matchMedia + переспрос по focus/visibilitychange; при system с 20:00 до рассвета — тёплая палитра (сдвиг в жёлто-янтарный, снижение синего), отключается явным выбором. Без чистого #000/#FFF; текст/фон ≥4.5:1, цель APCA Lc ≥75.

**6. Акцент.** AccentColor: пробный элемент → computed → сатурационный страж (отбраковка серого/чёрного/прозрачного) → двухпроходная подгонка OKLCH: (1) светлота от фона темы до контраста фон↔акцент ≥4.5:1; (2) до текст-на-акценте ≥4.5:1. Кэш сбрасывается по focus/visibilitychange. Отказ стража → дефолт: #4da3ff (dark/warm), #0b62c4 (light). Достигнутое ratio — в паспорт и футер. Эталон — коммит линии B (103 сочетания, ALL PASS); WCAG-скрипт audit_v273 общий.

**7. Типографика.** Стек `-apple-system, "Segoe UI", Roboto, "Noto Sans", Arial, sans-serif`; база 14 (--pml-fs), шкала 12–20 (контрол в «Комфорте»); интерлиньяж 1.5; строка ≤48ch; вес ≥400; сетка 8.

**8. Геометрия.** Развёрнутая: ширина 360 (ресайз 320–480), высота авто ≤80vh, min 320×360; радиус 12; все цели ≥44×44; focus-visible кольцо `--pml-ring` (2px + offset 2px).

**9. Компоновка.** Шапка: бейдж «ИМЯ vX.Y» (из mount(config)) + точка состояния (ok/run/warn/err) + сегментный тумблер темы (Авто/Свет/Тьма/Тепло; radiogroup/radio, roving tabindex, стрелки/Home/End, transform.translateX, ≥44px) + кнопка сворачивания. Тело: три фиксированные вкладки «Разведка / Действия / Журнал»; на вкладке ≤4 главных контрола + `<details>` «Ещё». Футер: статус aria-live + `<details>` «Комфорт» = движение выкл + кегль 12–20 + `<details>` «Паспорт». Свёрнуто: бейдж 44×44 с кольцом цвета состояния; разворот кликом.
Разведка: секции Каркас / Скролл / Мутации / Якоря (выход Модуля I: I-1 группы, I-2 скролл-перепись, I-3 мутации, I-4a/I-4b точки/якоря); struct рендерится секциями «заголовок + строки key: value», схема — контракт PML-STRUCT. Действия: реестр ядра, элемент `{id, label, hint?, disabled, run}`; busy: на время run() кнопки глушатся, бейдж = run. Журнал: свежее сверху, ≤200 записей, уровни info/ok/warn/err — цветная точка.

**10. Паспорт.** Имя/версия скрипта (из config); строка «Панель: PML-PANEL 1.0»; тема; акцент/откуда + ratio; движение; состояние разведки страницы; метрики скрипта; список хоткеев. Живые числа, подписи источников норм.

**11. Движение.** Переходы ≤200 мс (финал); циклов нет; мерцание ≤3 Гц; prefers-reduced-motion + ручной тумблер «Движение выкл» (persisted); тумблер темы замирает в обоих случаях; тосты не крадут фокус, не стакаются.

**12. Статус.** Одна aria-live=polite область; ≤80 символов; авто-скрытие 4 с; без очереди; прогресс — текстом, без модалок.

**13. Хоткеи.** Реестр Alt+{E,D,C,S,X,I}; модификатор Alt обязателен. MUST игнор при target = input/textarea/contenteditable. Конфликт: первый установленный побеждает; второй — warn в консоль + дубль кнопкой. Список активных — в паспорте; строка в «Журнал» при монтировании.

**14. Состояние.** `localStorage["pml_panel_v1"]` — JSON ≤512 байт, белый список (theme, fs, motion, collapsed, hotkeys, `pml_<script>_*`), только UI-настройки, запись в try/catch. Обновление/переустановка скрипта настройки не теряет. Хранилище страницы сверх этого ключа — запрещено; GM-адаптер в 1.0 не входит.

**15. Приватность.** 0 внешних запросов, 0 сетевых шрифтов/CDN; панель не читает контент страницы; разведка — только структурные агрегаты.

**16. Чек-лист (общий, гоняем оба).** P1 автопаудит контраста ≥4.5:1 PASS; P2 смена темы живьём; P3 системный акцент + ratio в паспорте; P4 reduced-motion и «Движение выкл» замораживают анимации; P5 хоткеи игнорируются в полях ввода; P6 все цели ≥44×44 (включая свёрнутый бейдж); P7 изоляция на «агрессивной» странице; P8 удаление узла → самовосстановление ≤2 с; P9 0 внешних запросов; P10 0 ошибок консоли; P11 бейдж↔панель; P12 настройки переживают перезагрузку; P13 синглтон; P14 три вкладки точными названиями, «Паспорт» доступен с любой вкладки.

**17. Переход.** Текущие панели живут; вшиваем в UACE v27.4 / SSEA v1.5 / панель исполнителя SSA-1. Потолок объёма — 260 строк.

Правки после заморозки — только через STP-2.
